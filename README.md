# KoishiAI — ข่าวและเครื่องมือ AI สำหรับคนไทย

**เว็บไซต์: [koishiai.com](https://koishiai.com/)** · [ภาษาไทย](https://koishiai.com/th) · [English](https://koishiai.com/en)

KoishiAI เป็นเว็บข่าวและความรู้ด้าน AI ภาษาไทย มีสามส่วนหลัก คือ ข่าว AI ในไทยและต่างประเทศ บทเรียนเชิงลึกแบบเป็นซีรีส์ และเครื่องมือฟรีที่ทำงานในเบราว์เซอร์ของคุณเอง

## เครื่องมือฟรี

ทุกเครื่องมือทำงานในเบราว์เซอร์ทั้งหมด ข้อความหรือไฟล์ที่คุณวางไม่ถูกส่งไปที่เซิร์ฟเวอร์ของเรา ไม่ต้องสมัครสมาชิก

| เครื่องมือ | ใช้ทำอะไร |
|---|---|
| [นับ Token ภาษาไทย](https://koishiai.com/th/tools/token-counter) | ดูว่าข้อความไทยกินกี่ token ใน GPT, Claude, Gemini, Typhoon และอื่น ๆ |
| [ข้อความไทยยาวแค่ไหนที่ AI รับได้](https://koishiai.com/th/tools/context-window) | เทียบขนาด context window เป็นความยาวข้อความไทย |
| [ราคา AI ต่อข้อความภาษาไทย](https://koishiai.com/th/tools/thai-ai-price) | เทียบค่าใช้จ่ายหลายสิบรุ่นต่อข้อความไทย เป็นเงินบาท |
| [ล้างข้อความไทยก่อนส่ง AI](https://koishiai.com/th/tools/thai-text-clean) | แก้สระหรือวรรณยุกต์เพี้ยนจากการคัดลอกจาก PDF |
| [เช็กว่าบอท AI เข้าเว็บได้ไหม](https://koishiai.com/th/tools/ai-crawler-check) | วาง robots.txt แล้วดูว่าบอทแต่ละตัวอ่านหน้าไหนได้ |
| [แปลงตัวเลขเป็นคำอ่านเงินบาท](https://koishiai.com/th/tools/baht-text) | 1,234.50 → หนึ่งพันสองร้อยสามสิบสี่บาทห้าสิบสตางค์ |
| [แปลง พ.ศ. ↔ ค.ศ.](https://koishiai.com/th/tools/thai-date) | แปลงปีและวันที่ พ.ศ. ค.ศ. ร.ศ. ถูกต้องถึงช่วงก่อนปี 2484 ที่ไทยขึ้นปีใหม่ 1 เมษายน |
| [สร้างและตรวจ JSON-LD](https://koishiai.com/th/tools/jsonld) | structured data สำหรับบทความ ร้านค้า และองค์กร |
| [ตรวจพรีวิวลิงก์ Facebook LINE X](https://koishiai.com/th/tools/link-preview) | ดูการ์ดก่อนแชร์ และวัดขนาดรูปจริง |
| [ตรวจ sitemap.xml](https://koishiai.com/th/tools/sitemap-check) | ตรวจตามกฎของ Google และ sitemaps.org |
| [ตรวจ hreflang เว็บสองภาษา](https://koishiai.com/th/tools/hreflang-check) | ดูว่าหน้าแต่ละภาษาชี้หากันถูกต้องไหม |

รวมทุกเครื่องมือ: [koishiai.com/th/tools](https://koishiai.com/th/tools)
